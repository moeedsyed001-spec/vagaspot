# Reference assets

- `comsats-islamabad-campus-sign-map.jpg` — user-uploaded photograph of the COMSATS University Islamabad campus map sign. Its legend provides 34 place labels and its blue outline is a visual boundary reference.

**Important:** This is a photographed sign, not a surveyed or georeferenced map. Do not derive latitude/longitude or a geofence radius directly from the pixels. Use an official GIS/KML/GeoJSON boundary where possible, or digitise against an aerial basemap in QGIS and field-validate it before enabling automatic campus detection.
